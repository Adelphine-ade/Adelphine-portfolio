My Projects

Bank Accounts Management System

A desktop-based Bank Accounts Management System developed using C#, Windows Forms, Object-Oriented Programming (OOP), and MySQL. The application is designed to manage customer bank accounts and perform common account operations.

The system allows users to create accounts with automatically generated account numbers, make deposits and withdrawals, calculate interest, search for accounts, and deactivate or restore accounts. Account information is stored and managed using a MySQL database.

C# .NET OOP MySQL Windows Forms

Key Features

  • Automatic account number generation
  • Account creation and management
  • Deposit and withdrawal operations
  • Interest calculation for savings accounts
  • Account search functionality
  • Account deactivation and restoration
  • MySQL database integration
